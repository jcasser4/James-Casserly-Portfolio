# Upload this GitHub update

Unzip this package and upload the files inside to the root of your `James-Casserly-Portfolio` repository. Do not upload the ZIP itself.

Replace these existing files when GitHub commits the update:

- `index.html`
- `styles.css`
- `script.js`

Also upload all of the new `media-*` files. These are the added GIFs/images used by the project detail galleries and the new Other projects section.

Suggested commit message:

`Add project GIFs and other projects media`

After GitHub Pages deploys, test:

`https://jcasser4.github.io/James-Casserly-Portfolio/?v=media-update`
